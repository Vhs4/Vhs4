## Selected Projects

### [Iara 2.0](https://barkus.com.br) — Multi-Agent AI for Education
Production AI platform deployed in Brazilian EdTech. Sole engineer responsible for architecture, agent orchestration, and infrastructure. Built on LangGraph with TypeScript and Python backends on GCP.

### AI Multi-Agent Video Generation SaaS — Codrix
Generates complete commercial videos from a text briefing using 12 agents orchestrated in LangGraph with persistent state and failure recovery. Quality gates allow critical agents to score each phase and trigger automatic regeneration; self-healing detects safety blocks, timeouts, and failures without human intervention. Full videos with narration and character consistency produced in ~5–10 min.  
`TypeScript` `LangGraph` `Next.js` `Fastify` `BullMQ` `Redis` `pgvector` `ffmpeg` `Veo` `Claude`

### B2B Prospecting Platform with AI — Codrix
Lead prospecting platform with data enrichment and AI-powered qualification. Two-step domain enrichment pipeline (Apify actor + verifier agent) and a real-time site discovery agent using Agno + GPT-4o-mini.  
`Next.js` `NestJS` `Python` `Supabase` `OpenAI`

### Learning Management System with AI
Full LMS built for a PhD professor at a renowned Brazilian university — sole engineer across architecture, frontend, backend, infra, and deploy. GPT-4o question generation from PDFs and texts; AI-powered learning deficit analysis with per-student diagnostics.  
`Next.js` `NestJS` `PostgreSQL` `Docker` `Traefik`

### Fully Ecosystem — Large-Scale Health Platform
Full-stack development on a health & wellness platform backed by R$200M from Prudential, serving 50k+ active users across PT, EN, and ES. Built critical modules including the user digital wallet (transactions, balance, history), mental health flows, and financial wellness features using NestJS, Node.js, React, Kotlin, Docker, and AWS (Lambda, S3). Helped raise the app's public rating from 2.8 to 4.3 on iOS and 2.5 to 4.9 on Android through continuous engineering improvements.

### Nebulab — NASA Space Apps Challenge
AI-powered app built for the 2023 NASA Space Apps Challenge. Achieved regional winner status and global nomination out of thousands of international teams.
